# Спільний перегляд (десктоп)

Хост обирає серію на своєму комп'ютері, решта дивляться її в оригінальній якості (плеєр mpv).
Файл не перекодовується, а передається шматками напряму від хоста.

## Збірка .exe (без встановлення будь-чого)
1. Створіть новий репозиторій на GitHub і завантажте туди ВСЕ з цієї папки (разом з папкою .github).
2. Вкладка Actions -> build -> Run workflow. Через 5-10 хвилин у розділі Artifacts буде WatchParty-Windows.
3. Скачайте, розпакуйте, роздайте друзям .exe (портативний, встановлення не потрібне).

## Запуск з вихідників (для перевірки)
    npm install
    npm start
Покладіть mpv.exe в папку mpv/ поруч з app.js (або вкажіть шлях кнопкою в програмі).
